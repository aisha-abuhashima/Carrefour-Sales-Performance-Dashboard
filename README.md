# Carrefour-Sales-Performance-Dashboard
### Project Overview
This repository contains a data analysis and visualization project developed as a graduation/training practice during my enrollment at *Tech-Mind Data & Programming Academy*. 

> *Note on Data Authenticity:* The dataset utilized for this project was synthesized entirely at random for training and educational purposes; it does not represent any real-world operational or financial metrics of Carrefour.

### Repository Contents
* *Carrefour_Sales_Data.xlsx*: The raw synthesized dataset including transactions, stores, and products.
* *Carrefour_Sales_Dashboard.pbix*: The complete Power BI file including data model, DAX measures, and interactive visuals.
* *Dashboard_Screenshot.png*: A high-resolution preview of the final dashboard layout.

### Technical Toolkit
* *Data Transformation:* Power Query (Excel/Power BI) for cleaning and normalization.
* *Data Modeling:* Star Schema design establishing clean fact-to-dimension relationships.
* *Visualization:* Power BI Desktop tailored to brand guidelines.
